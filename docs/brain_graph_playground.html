Brain graph playground

All four evolved architectures, rendered via Rust WASM (brain_diagram.rs — same path as nn_viz.rs). GoO is inspired by Graph-of-Thoughts: it supports branching (multiple Gen children) and merging (Agg / Best), but not yet self-loop refinement or backtracking like the LLM GoT paper figure. Until recently, mutations always chained n-1 → n, which made graphs look linear — that is fixed now.
